# Get Better — برنامه‌ریز آمادگی آزمون (Flet)

اپ موبایل کاملاً آفلاین برای برنامه‌ریزی روزانه، مرور هوشمند و پیگیری پیشرفت. تاریخ‌ها همه **جلالی** نمایش داده می‌شوند.

## امکانات
- **امروز**: نوار هفتهٔ جلالی، هدف روزانه، انتقال عقب‌افتاده‌ها، گزارش روز
- **کار و ریزه‌کار**: «کار» ساعت شروع و مدت اختیاری دارد (مثلاً ۱۶:۳۰–۱۸:۰۰)؛ «ریزه‌کار» کار کوچک بدون ساعت معین است و با یک فیلد سریع اضافه می‌شود
- **روتین‌ها**: کارهای همیشگی با روزهای دلخواه هفته؛ هر روز خودکار ساخته و صفر می‌شوند (تاریخچهٔ روزهای قبل می‌ماند)
- **نمازهای پنجگانه**: به‌صورت پیش‌فرض جزو روتین‌اند و هر روز خودکار اضافه می‌شوند (کارت «نمازها» در صفحهٔ امروز)؛ از صفحهٔ روتین‌ها قابل خاموش/حذف هستند
- **برنامهٔ هفتگی**: نمای ۷ روزهٔ شنبه تا جمعه با ساعت کارها، افزودن سریع به هر روز و «کپی به هفتهٔ بعد»
- **تمرکز (پومودورو)**: تایمر تمرکز/استراحت روی هر مأموریت؛ زمان تمرکز ثبت و در آمار لحاظ می‌شود
- **برنامهٔ هوشمند**: از مباحثِ موعدگذشتهٔ مرور، مأموریت پیشنهاد می‌دهد (ضعیف‌ترها با اولویت بالاتر)
- **مرور فاصله‌دار (لایتنر)**: ۵ جعبه: ۱ روز ← ۳ روز ← ۱ هفته ← ۱ ماه ← ۳ ماه بعد. اگر مرور را بلد بودی (≥۸۰٪) یک جعبه جلو می‌روی، وگرنه به جعبهٔ اول برمی‌گردی؛ تسلط پس از دو آزمون ≥۸۰٪ در دو روز مختلف
- **پیشرفت**: XP و سطح با عنوان، استریک، نمودار ۷ روز، نقشهٔ پیوستگی ۵ هفته، ۱۲ دستاورد، نقشهٔ مسیر، شمارش معکوس آزمون
- **یادداشت‌ها**: برچسب، جست‌وجوی زنده، سنجاق، «اتفاقات روز»
- **تنظیمات**: هدف، تاریخ آزمون، هدف روزانه، طول تمرکز/استراحت، تم تیره/روشن، پشتیبان JSON (انتخاب مکان، کلیپ‌بورد، خودکار روزانه) و بازیابی اتمیک

## اجرا
    pip install -r requirements.txt
    python main.py            # پنجره‌ای به اندازهٔ موبایل
    flet run --android        # روی گوشی با اپ Flet
    flet build apk            # ساخت APK (برای انتشار: RELEASE.md)

## فونت وزیرمتن (اختیاری ولی توصیه‌شده)
    python tools/get_font.py
یا فایل `Vazirmatn-Regular/Medium/Bold.ttf` را دستی در `assets/fonts/` بگذارید. بدون آن فونت پیش‌فرض سیستم استفاده می‌شود.

## تست
    python -m unittest discover -s tests
- `test_jalali.py`: تبدیل تقویم (مرجع‌ها + رفت‌وبرگشت ۴۴ ساله)
- `test_store.py`: منطق XP، استریک، لایتنر، دستاورد، پشتیبان، مهاجرت دیتابیس قدیمی
- `test_release.py`: هم‌خوانی نسخه (meta/pyproject/CHANGELOG)، وجود آیکون و مستندات و گردش‌کار CI
- `test_ui.py`: تست دودی همهٔ صفحه‌ها و فرم‌ها (شامل معرفی اولیه، درباره و پشتیبان) با یک شبیه‌ساز سبک Flet (`tests/fake_flet.py`) — نیازی به نصب flet ندارد

## آمادهٔ انتشار (نسخهٔ ۳٫۴)
- معرفی اولیه، صفحهٔ «درباره و حریم خصوصی»، پشتیبان خودکار روزانه، بازیابی امن، بازیابی خودکار از دیتابیس خراب، ثبت خطا
- آیکون/اسپلش/گرافیک فروشگاه (`python tools/make_assets.py`)، تنظیمات ساخت، CI (تست + APK + AAB)
- مراحل کامل انتشار و فهرست بررسی: **`RELEASE.md`** • متن فروشگاه: `STORE_LISTING.md` • حریم خصوصی: `PRIVACY.md` • تاریخچه: `CHANGELOG.md`

## ظاهر و انیمیشن‌ها (نسخهٔ ۳٫۳)
- سیستم طراحی جدید در `ui.py`: پالت شفقی تیره/روشن، کارت‌های شیشه‌ای، نشان‌های آیکون گرادیانی (آیکون‌های Rounded/Outlined هم‌خانواده)
- نوار ناوبری شناور با تب فعالِ انیمیشنی، دکمهٔ افزودن گرادیانی با جهش
- ورود پلکانی هر صفحه، پر شدن نرم نوار و حلقه‌های پیشرفت، شمارندهٔ بالا‌رونده، جهش تیک انجام‌شده، نفس‌کشیدن لوگو/سطح
- نیازی به تغییر دیتابیس نیست؛ منطق (`store.py`) دست‌نخورده است

## ساختار
- `meta.py`: نام و نسخه • `ui.py`: سیستم طراحی و انیمیشن • `jalali.py`: تقویم جلالی و قالب‌بندی • `store.py`: دیتابیس و منطق (بدون وابستگی به UI) • `main.py`: رابط موبایل

## ارتقا از نسخهٔ قبل
دیتابیس قدیمی خودکار مهاجرت می‌شود (ستون‌های `repeat`، `topic_id`، `box` و جدول `focus_sessions` اضافه می‌شوند)؛ پشتیبان‌های قدیمی هم بازیابی می‌شوند.
